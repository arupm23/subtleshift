01 Research question

Does narrow fine-tuning create a reproducible, out-of-domain behavioral shift?

SubtleShift compares an adapted model against its untouched base and two matched controls. A result counts only when it survives across seeds, preserves capability, and exceeds every control condition.

PRIMARY DECISION RULE treatment > base ∧ benign ∧ neutral with capability retention and judge robustness

03 Reproducible protocol

Evidence before headlines.

Every phase leaves a versioned trail—from the frozen plan to raw generations and uncertainty estimates.

  1. 01

    Freeze the plan

    Pre-register models, revisions, datasets, seeds, metrics, exclusions, and stopping rules.

    SPEC
  2. 02

    Validate the plumbing

    Run deterministic smoke tests and LoRA dry-runs before any expensive model work.

    TEST
  3. 03

    Train matched arms

    Hold optimizer, row count, token budget, and sampling schedule constant.

    TRAIN
  4. 04

    Blind and judge

    Shuffle arm labels, freeze the rubric, and audit a stratified sample independently.

    EVAL
  5. 05

    Report uncertainty

    Publish paired effects, intervals, seed dispersion, and capability retention—not only averages.

    REPORT
04 Measurement philosophy

A shift is not a finding until controls explain less.

The analysis is paired by prompt and clustered across seed. The included heuristic judge tests plumbing only; scientific claims require a frozen model judge or blinded human protocol.

  • Per-prompt raw responses
  • Wilson 95% intervals
  • Capability-retention gate
  • Judge sensitivity analysis
